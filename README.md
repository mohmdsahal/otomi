# Otomi

### Manga reader + full AniList client, in one app

Otomi started as a fork of [Mihon](https://github.com/mihonapp/mihon) — keeping its manga reader, extension-source engine, and downloader — and is being built out into a complete AniList client as well: browsing, tracking, favourites, activity feed, and more, alongside the reading experience. The AniList feature set is inspired by [Otraku](https://github.com/lotusreve/otraku), AniList's own Flutter client, though no code is shared between the two — Otomi's AniList integration is written independently against AniList's GraphQL API.

**Status: early, active development.** Core AniList data (collection, discovery, media/character/staff/studio pages, favourites, activity feed) is wired up; UI screens for these features are still being built. Not yet ready for general use.

[![License: Apache-2.0](https://img.shields.io/github/license/mohmdsahal/otomi?labelColor=27303D&color=0877d2)](/LICENSE)

## Features

* Local manga reading, with a configurable reader (multiple viewers, reading directions, more).
* Full AniList integration *(in progress)*: browse and search anime/manga, view media/character/staff/studio details, manage your collection and favourites, read and interact with the activity feed.
* Tracker support: MangaBaka, MyAnimeList, AniList, Kitsu, MangaUpdates, Shikimori, Bangumi, and Hikka.
* Categories to organize your library.
* Light and dark themes.
* Scheduled library updates for new chapters.
* Local or cloud backups.

## Credits

Otomi is a fork of [Mihon](https://github.com/mihonapp/mihon), itself a fork of Tachiyomi. Its AniList feature set is inspired by [Otraku](https://github.com/lotusreve/otraku). Thank you to the contributors of both projects.
